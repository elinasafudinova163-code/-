### Описание программы

**Training Planner** – это GUI-приложение для планирования и учёта тренировок.  
Приложение позволяет добавлять записи о тренировках, фильтровать их по типу и дате, сохранять и загружать данные в формате JSON, а также удалять отдельные записи или весь список целиком.

### Возможности:
- Добавление тренировок с указанием даты, типа и длительности (в минутах)  
- Фильтрация тренировок по типу (Бег, Плавание, Силовая, Йога, и др.)  
- Фильтрация по дате (конкретная дата или диапазон)  
- Сохранение данных в JSON-файл  
- Загрузка данных из JSON-файла  
- Удаление выбранной тренировки  
- Очистка всего списка тренировок  
- Валидация вводимых данных (проверка формата даты, положительное число для длительности)  

### Инструкция по запуску

#### Требования:
- Python 3.6 или выше  
- Установленная библиотека Tkinter (обычно идёт в комплекте с Python)  

#### Запуск:
1. Откройте терминал или командную строку  
2. Перейдите в директорию проекта:  
   ```bash
   cd training-planner
3. Запустите приложение:
   ```bash
   python main.py
   ```

##Примеры использования

###Добавление тренировки:

1. Заполните все поля формы:
   ```bash
   --*Дата тренировки:** "2026-04-25"
   ```
   ---
   · Тип тренировки: Бег
   · Длительность (мин): 45
2. Нажмите кнопку Добавить тренировку
3. Тренировка появится в таблице внизу окна

###Фильтрация:

· Фильтр по типу: Выберите тип из списка (например, "Плавание")
· Нажмите кнопку Фильтрация
· В таблице отобразятся только записи выбранного типа
· Фильтр по дате: Введите начальную и конечную дату
· Нажмите кнопку Фильтрация
· В таблице отобразятся тренировки за указанный период

###Сохранение данных в JSON-файл:

· Файл: training_data.json
· Сохранить: Нажмите кнопку Сохранить в JSON
· Сохранение: Данные будут записаны в файл

###Загрузка данных из JSON-файла:

· Файл: training_data.json
· Загрузить: Нажмите кнопку Загрузить из JSON
· Данные: Все тренировки из файла появятся в таблице

###Очистка:

· Очистить: Выберите конкретную запись и нажмите Удалить тренировку
· Очистить всё: Нажмите Очистить всё, подтвердите действие в диалоговом окне
После добавления попробуйте:
- Очистить только тренировки типа "Бег"
- Найти тренировки в диапазоне дат с 2026-04-01 по 2026-04-30
- Сохранить данные в JSON, закрыть приложение, затем загрузить обратно

## Валидация данных

Приложение проверяет:
- Все поля должны быть заполнены
- Дата должна быть в формате ГГГГ-ММ-ДД
- Длительность должна быть положительным числом
- При удалении необходимо выбрать тренировку из таблицы
- При очистке всего списка требуется подтверждение
